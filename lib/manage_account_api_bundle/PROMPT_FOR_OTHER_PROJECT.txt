Ensure these dependencies exist in your `pubspec.yaml`:
```yaml

  flutter:
    sdk: flutter
  flutter_riverpod: ^2.6.1
  http: ^1.2.2
  file_picker: ^11.0.3 # or ^8.0.0+
  http_parser: any
```

Run `flutter pub get`.

---

### STEP 2: Wrap App with `ProviderScope`
In your `main.dart`, wrap the root application widget in `ProviderScope`:
```dart
import 'package:flutter/material.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';

void main() {
  WidgetsFlutterBinding.ensureInitialized();
  runApp(
    const ProviderScope(
      child: MyApp(),
    ),
  );
}
```

Optional: To customize the API base URL:
```dart
import 'manage_account_api_bundle/core/network/api_client.dart';

// In main() or on app init:
ApiClient.setBaseUrl('https://api.bnxmail.com');
```

### BUNDLE STRUCTURE OVERVIEW:
- `manage_account_api_bundle/screens/manage_account_screen.dart`: Complete 7-tab Manage Account screen.
- `manage_account_api_bundle/widgets/account_menu_card.dart`: Top-bar dropdown profile card with multi-account switcher.
- `manage_account_api_bundle/core/widgets/avatar_widget.dart`: Multi-color initial/remote image avatar widget.
- `manage_account_api_bundle/core/theme/`: `colors.dart`, `neumorphic.dart`.
- `manage_account_api_bundle/core/network/`:
  - `api_client.dart`: Central HTTP client with auto 401 refresh & uniform error handling.
  - `token_service.dart`: Cross-platform resilient session and token persistence.
  - `api_exception.dart`: Typed API exception.
- `manage_account_api_bundle/data/providers/`:
  - `account_provider.dart`: Account list, switching, sign-out, avatar upload/remove.
  - `settings_provider.dart`: User settings, signatures, 2FA, language, text style.
- `manage_account_api_bundle/data/repositories/`:
  - `user_repository.dart`: Profile, sub-IDs, connected emails, devices.
  - `settings_repository.dart`: General settings, signatures, 2FA setup/verify.
  - `storage_repository.dart`: Mailbox & account storage quotas.
  - `subscription_repository.dart`: Active subscriptions & plans.
  - `auth_repository.dart`: Login, logout, multi-account session management.
- `manage_account_api_bundle/models/`:
  - `account_model.dart`, `user_model.dart`, `user_settings_model.dart`, `two_factor_model.dart`, `signature_model.dart`, `blocked_contact_model.dart`.
